## 2024-05-18 - Prevent Unnecessary Eager Loading in SQLAlchemy
**Learning:** In asynchronous SQLAlchemy (`AsyncSession`), synchronous lazy-loading is not possible and raises `MissingGreenletError`. This codebase configures relationships with `lazy='selectin'` to avoid this, but that causes eager loading for EVERY query involving the model, even when relationships aren't needed (like list endpoints returning Pydantic schemas that only need scalar fields). This leads to N+1 equivalent query execution overhead.
**Action:** When querying lists with SQLAlchemy where relationships are not required by the output schema, explicitly use `.options(raiseload('*'))`. This safely prevents eager loading of relationships (overriding `lazy='selectin'`) and protects against silent data omission by throwing an exception if downstream code inadvertently accesses the relationship.
