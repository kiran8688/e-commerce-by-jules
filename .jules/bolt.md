## 2026-05-20 - Prevent Eager Loading on Serialized Scalar Schemas
**Learning:** By default, several SQLAlchemy relationships on the `Product` model are configured with `lazy="selectin"`, which triggers multiple asynchronous queries for related objects (categories, images, reviews, inventory) even when they are not explicitly accessed. If a FastAPI endpoint returns a Pydantic schema (like `ProductOut`) that only serializes scalar columns, these background queries are entirely wasted, leading to significant database overhead on list views.
**Action:** When querying lists for endpoints that map to base schemas, always intercept the default lazy-loading behavior by passing `.options(raiseload('*'))` to the select statement. This prevents unnecessary round-trips and guarantees that no hidden data accesses occur during serialization.
