## 2024-05-24 - SQLAlchemy `raiseload('*')` vs `noload('*')` for N+1 Prevention
**Learning:** `raiseload('*')` is an excellent structural assertion to prevent unintended eager loading or lazy loading. Applying `raiseload('*')` to a query blocks all relationship loading and causes Pydantic to loudly fail (500 error) during serialization if the schema attempts to access any relationship (because lazy loading is disabled in async SQLAlchemy). It ensures that relationship access is explicitly documented.
**Action:** When returning Pydantic response schemas (like `ProductOut`) that omit relationship fields, prevent the underlying SQLAlchemy model from performing wasted N+1 eager loads (e.g., caused by `lazy='selectin'`) by passing `raiseload('*')` from the router. Pass these load options as an argument to generic service-layer functions to avoid breaking other callers.
