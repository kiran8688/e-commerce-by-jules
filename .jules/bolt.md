## 2024-05-18 - Prevent N+1 queries from lazy='selectin' in FastAPI endpoints returning Pydantic schemas
**Learning:** In asynchronous SQLAlchemy (`AsyncSession`), relationships configured with `lazy='selectin'` are automatically eagerly loaded via separate `IN` queries. If a FastAPI endpoint returns a Pydantic schema that omits these relationship fields, the database still performs the eager loads, resulting in significant N+1-style performance overhead that is silently discarded by Pydantic.
**Action:** Use `.options(raiseload('*'))` at the router level when querying lists of models where relationships are not needed by the response schema. Pass this as a parameter to the service layer to prevent wasted eager loading while protecting against silent data omission errors.
