## 2025-10-24 - [Avoid `selectin` Eager Loads for Unused Relationships]
**Learning:** In async SQLAlchemy with models using `lazy='selectin'` for their relationships, simple queries (like `select(Product)`) will trigger an additional query for *each* relationship under the hood to satisfy the eager loading. For objects like `Product` with 4 relationships, fetching the catalog list resulted in up to 4 unnecessary queries if the client only needed the base object schema (`ProductOut`).
**Action:** When querying models that use `selectin` eager loading by default, and the API schema does not require those relationships, always append `.options(raiseload('*'))` to the query to safely block the extraneous queries and raise an exception if downstream code accidentally relies on them.
