## 2024-05-23 - Prevent N+1 queries from lazy='selectin' with raiseload
**Learning:** The project uses `lazy='selectin'` on relationships in SQLAlchemy models, which is necessary for async environments. However, this causes eager loading of relationships even when the corresponding API endpoint schema (e.g., `ProductOut` returning a list) drops this data. This results in unnecessary database queries.
**Action:** When creating endpoints that return lists of objects, apply `raiseload()` to relationships that the output schema doesn't need. Pass `load_options` from the router layer to the service layer instead of hardcoding it in the service, preserving the service's reusability. For example: `load_options=[raiseload('*')]` for all relationships, or `load_options=[raiseload(Order.user)]` for specific ones.
