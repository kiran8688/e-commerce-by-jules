## 2024-05-29 - Prevent Unintended Eager Loading with raiseload in SQLAlchemy
**Learning:** Returning Pydantic schemas (e.g., `ProductOut`) that omit relationship fields does not stop SQLAlchemy from performing eager loading (e.g., `lazy='selectin'`), leading to wasted database queries and memory overhead. Also, asynchronous SQLAlchemy cannot lazily load on access, further highlighting the need to explicitly manage loading strategies.
**Action:** When a router endpoint uses an output schema that doesn't need relationship data, explicitly pass `raiseload('*')` (or target specific relationships) to the query via `options()`. Pass these load options from the router down to generic service-layer functions rather than hardcoding them, allowing the service functions to remain reusable.
