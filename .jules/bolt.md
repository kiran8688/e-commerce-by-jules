## 2024-05-30 - Prevent unnecessary eager loading with raiseload('*')
**Learning:** In SQLAlchemy, relationships configured with `lazy="selectin"` on models (like `Product.images`, `Product.inventory`, `Product.category`, `Product.reviews`) will automatically execute additional queries when the parent model is loaded, even if those relationships aren't accessed. When returning simple lists in API endpoints where the Pydantic schema (like `ProductOut`) doesn't include those relationship fields, this results in a hidden N+1-like pattern (e.g., 4 unnecessary queries per API call).
**Action:** When Pydantic response schemas omit relationship fields, explicitly pass `.options(raiseload('*'))` to the SQLAlchemy query. To avoid breaking generic service functions that other endpoints might rely on, pass `load_options=[raiseload('*')]` down from the router endpoint to the service function.
