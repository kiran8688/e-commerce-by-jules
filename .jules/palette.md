## 2026-06-20 - [Auth Form Accessibility]
**Learning:** Found that the Auth form was lacking basic HTML form accessibility features like label to input association via htmlFor and id, input type submit vs button for keyboard submission, and visual focus states.
**Action:** When creating forms, always ensure labels have htmlFor matching input ids, required inputs have visual indicators, inputs have clear focus-visible outlines, and form submit buttons have type="submit".
