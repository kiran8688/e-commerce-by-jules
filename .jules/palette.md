## 2026-06-15 - [Added Native Tooltips, Expanded ARIA States, and Keyboard Focus Rings to Icon-Only Buttons]
**Learning:** For icon-only buttons or links, `aria-label` is not sufficient because it only benefits screen reader users; a `title` attribute matching the `aria-label` should also be provided to function as a native tooltip for sighted users. Additionally, toggles must dynamically update their `aria-label` and `title` to describe the action they will perform, communicate their state using `aria-expanded`, and include clear visible focus styling (e.g., `focus-visible:ring-2`) to ensure full keyboard navigation accessibility.
**Action:** Always pair `aria-label` with `title` for icon-only interactive elements to serve both assistive tech and sighted users, dynamically update ARIA attributes on toggles, and use `focus-visible` to support keyboard navigation.
