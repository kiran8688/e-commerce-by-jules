## 2026-06-21 - [Brand-Aligned Focus Rings for Icon Controls]
**Learning:** Default browser focus outlines on transparent icon-only buttons often look misaligned or clipped. Establishing a brand-aligned focus ring pattern using specific Tailwind classes significantly improves keyboard navigation clarity and aesthetics.
**Action:** Always apply explicit, branded `focus-visible` styles (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[#0050d4]`) to interactive icon elements to ensure accessible and aesthetically pleasing keyboard navigation.
